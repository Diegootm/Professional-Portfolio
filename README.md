# Diego Tejerina — Personal Portfolio

A personal portfolio website built from scratch with vanilla HTML, CSS and JavaScript. No frameworks, no dependencies — just clean, handwritten code.

## Live Demo

🔗 [View Deploy](https://diegootm.github.io/Professional-Portfolio/)

## About

This portfolio showcases my work as a Full Stack Developer, UX/UI Designer and Web Programming Instructor. It includes sections for about me, technical skills, and featured projects.

## Built With

- **HTML5** — semantic structure and markup
- **CSS3** — custom properties, flexbox, grid, animations and responsive design
- **JavaScript** — particle canvas, custom cursor, typewriter effect, scroll reveal and smooth navigation

## Features

- Animated particle background with mouse interaction
- Custom cursor with ring follow effect
- Typewriter role animation in the hero section
- Scroll reveal animations on all sections
- Fully responsive layout for desktop, tablet and mobile
- Glassmorphism UI style
